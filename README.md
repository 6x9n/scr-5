# مسح نتائج الطلاب تلقائيًا على GitHub Actions

سكريبت يفحص أرقام الجلوس من **2910423** إلى **2980000** على موقع nategafany.com ويحفظ النتائج — يعمل في سحابة GitHub على مدار الساعة **بدون تشغيل جهازك**، مع استئناف تلقائي لو انقطع الجوب.

## الملفات

| الملف | الوظيفة |
|---|---|
| `scrape.py` | السكريبت: يفحص الأرقام، يحفظ التقدم كل 100 طالب |
| `checkpoint.json` | نقطة الاستئناف: آخر رقم تم فحصه + النتائج المجمعة (303 حاليًا) |
| `student_results.json` | النتائج النهائية مرتبة تنازليًا حسب النسبة (تُحدث تلقائيًا) |
| `.github/workflows/scrape.yml` | الجدولة: يشغّل السكريبت كل 6 ساعات |

## خطوات التشغيل (مرة واحدة)

1. أنشئ مستودعًا جديدًا على GitHub (عام أو خاص — مجاني في الحالتين):
   - من github.com اضغط **New repository**، سمّه مثلًا `results-scraper` (لا تختار README)، ثم انسخ رابط الريبو
2. ارفع الملفات من جهازك:
   ```bash
   cd D:\Tools\discord-badge-manager-main\exam-scraper
   git init
   git add .
   git commit -m "initial"
   git branch -M main
   git remote add origin <رابط-الريبو>
   git push -u origin main
   ```
3. فعّل صلاحية الكتابة للسكريبت: من الريبو → **Settings → Actions → General → Workflow permissions** → اختر **Read and write permissions** → Save
4. شغّل يدويًا الآن (بدل ما تنتظر الجدولة):
   - من الريبو → تبويب **Actions** → `scrape-student-results` → زر **Run workflow** → Run workflow

## بعد التشغيل

- السكريبت يشتغل حتى **5.5 ساعات** ثم يحفظ التقدم ويخرج، والجدولة تشغّله تلقائيًا كل 6 ساعات حتى يخلص (تقديريًا 1.5-2 يوم)
- كل checkpoint بيتحفظ في الريبو كـ commit — افتح `student_results.json` من أي وقت لترى النتائج حتى الآن
- آخر رقم اشتغل عليه تشوفه في `checkpoint.json` (حقل `next_seat`)
- لما يخلص: حقل `done: true` يظهر في `checkpoint.json` و `student_results.json` يبقى النسخة النهائية الكاملة

## ملاحظات

- لو عايز تسرّع: خفف التأخير بمتغير البيئة `REQUEST_DELAY` (مثلًا `0.8` بدل `1.5`) — لكن دا يزيد احتمالية حد 429
- لو الريبو خاص والـ Actions خلصت الدقائق المجانية (2000 دقيقة/شهر): المشروع كله بيتكلف ~35-40 دقيقة من وقت التشغيل الفعلي، فمش هتوصل للحد
- تقدر تشغّل السكريبت محليًا كمان: `python scrape.py` — بيشتغل عادي وبيحفظ الملفات (بدون commits لو مش داخل مستودع git)
